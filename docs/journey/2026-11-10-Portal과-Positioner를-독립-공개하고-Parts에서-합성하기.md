# 2026-11-10 — Portal과 Positioner를 독립 공개하고 Parts에서 합성하기

## 문제

Autocomplete의 Parts를 구현한 뒤 Portal과 Positioner가 다른 팝업에서도 반복될
가능성을 검토했습니다. 실제 구현에서도 Autocomplete, Popover, Dialog와
AlertDialog의 Portal은 클라이언트 마운트를 기다리고 지정한 컨테이너에 내용을
렌더링하는 같은 동작을 가지고 있었습니다. Autocomplete와 Popover의 Positioner는
기준 요소 옆의 좌표 계산, 화면 경계 보정, 표시와 제거, 크기 변수와 위치 갱신을
각각 구현하고 있었습니다.

중복을 줄이더라도 각 패턴의 의미와 동작을 유지해야 했습니다. Autocomplete는
입력에 포커스를 유지하며 추천 목록을 탐색합니다. Popover는 대화상자 안으로
포커스를 이동합니다. 배치가 비슷하다는 이유로 한 패턴을 다른 패턴의 기반으로
사용하면 포커스와 역할이 배치 구현에 결합할 수 있었습니다.

## 접근 방식

먼저 각 패턴의 공개 Parts를 유지하면서 공통 동작을 내부 Portal과 기준 요소에
붙는 Positioner로 옮기는 방안을 검토했습니다. 이 구조에서는 공개 Part가 자신의
컨텍스트에서 상태와 Ref를 읽고 공통 구현에 전달합니다. 공통 구현이 특정 패턴의
존재를 알 필요가 없으므로 DOM 동작을 재사용하면서 역할과 포커스 정책을 각
패턴에 유지할 수 있습니다.

사용자는 공통 컴포넌트를 외부에서도 사용할 수 있다는 점을 제시했습니다.
Portal과 Positioner를 각각 독립 폴더에 구현하고 공개하면 사용처가 자신의
컴포넌트에도 동일한 DOM 이동과 배치를 적용할 수 있습니다. 내부 모듈로 두는
방안은 재사용 범위를 라이브러리 내부로 제한합니다. 공개 방안에서는 독립 사용
계약을 설명하고 검증해야 하지만, 이미 확인된 공통 동작을 라이브러리 내부와
외부에서 함께 사용할 수 있습니다.

Positioner라는 이름이 같은 모든 Part를 하나로 묶을지도 구분했습니다.
Dialog의 Positioner는 화면 배치와 바깥 스크롤을 구성하는 컨테이너입니다.
[기존 Dialog 결정](./2026-10-29-Dialog의-배치와-바깥-스크롤을-Content에서-분리하기.md)도
Content의 의미와 포커스 경계에서 배치 책임을 분리하는 데 목적이 있습니다.
이 컨테이너에는 기준 요소 옆의 좌표 계산이 없으므로, 공개 Positioner에 함께
포함할 공통 동작이 확인되지 않았습니다.

## 해결

Portal과 Positioner를 독립된 공개 컴포넌트로 제공합니다. 각 컴포넌트는 별도
소스 폴더와 공개 진입점을 갖습니다. 사용처는 이를 직접 사용할 수 있고,
Autocomplete와 Popover 같은 패턴은 공개 컴포넌트를 자신의 Parts 안에서
가져다 사용합니다.

Portal은 DOM 컨테이너 이동과 클라이언트 렌더링 경계를 제공합니다.
각 패턴의 Portal Part는 자신의 열림 상태에 맞춰 표시 여부를 연결합니다.
Positioner는 기준 요소에 붙는 배치와 표시 생명주기를 제공합니다.
Autocomplete.Positioner는 Input의 Ref와 열림 상태를 연결하고,
Popover.Positioner는 Trigger와 화살표, 배치 완료 후의 동작을 연결합니다.
Props와 Ref 합성은 각 Part의 사용자 지정 요소에도 유지합니다.

공통 컴포넌트의 공개 범위는 DOM 이동과 배치입니다. 역할, 접근 가능한 이름,
추천 탐색, 선택, 포커스 이동과 닫기 정책은 각 패턴이 계속 소유합니다.
공개 컴포넌트만 직접 사용하는 경우에는 사용처가 콘텐츠에 맞는 접근성 동작을
완성해야 합니다. Dialog와 AlertDialog의 Positioner는 기존 화면 배치용
컨테이너로 유지합니다.

이 선택은 각 패턴의 상태를 자동으로 연결하는 기존 Parts와, 같은 기능을
독립적으로 조합할 수 있는 공개 컴포넌트를 함께 제공하는 결정입니다.
중복을 제거하는 경계를 특정 패턴의 상태나 포커스 정책까지 넓히지 않습니다.
세부 Props와 사용 예시는 각 컴포넌트 문서에서 다룹니다.
