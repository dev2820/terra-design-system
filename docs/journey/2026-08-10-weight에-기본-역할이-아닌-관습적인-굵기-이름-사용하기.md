# 2026-08-10 — Weight에 기본 역할이 아닌 관습적인 굵기 이름 사용하기

## 문제

Typography의 Weight를 단계로 정의하면서 각 굵기를 숫자로만 구분할지, 이름을
붙일지 결정해야 했다. 숫자 단계는 다른 Foundation과 형태를 맞추고 확장하기
쉽지만, 글꼴 굵기는 이미 100부터 900까지 관습적인 값과 이름이 널리 쓰이고
있어 별도의 순서 체계를 만드는 이점이 크지 않았다.

400을 `Default`라고 부르는 방안도 검토했다. 가운데에 놓인 대표적인 굵기를
알려주기 쉽지만, `Default`는 굵기 자체보다 시스템이나 Recipe가 기본으로
선택한 역할로 읽힌다. 어떤 제품이나 Recipe가 500을 기본 본문 굵기로 사용하면
400이라는 값과 기본 선택이라는 의미가 어긋날 수 있었다.

## 접근 방식

Weight를 `Weight 1`, `Weight 2`처럼 숫자로 나누면 특정 값에 덜 종속되고 단계를
추가하기 쉽다. 그러나 글꼴 굵기는 무한히 늘어나는 연속적인 Foundation이라기보다
이미 통용되는 이름과 값의 범위가 있으며, 숫자가 기존의 굵기 값과 함께 등장하면
두 종류의 숫자를 구분해야 한다.

관습적인 이름을 사용하면 `Regular`, `Medium`, `Semibold`, `Bold`가 각각 어떤
굵기를 나타내는지 직접 전달할 수 있다. 300 이하나 800 이상의 굵기는 큰 제목과
브랜드 표현처럼 필요한 경우가 있지만 일반적인 제품 UI에서 항상 요구되지는
않으므로, 모든 Token Set에 기본으로 요구하지 않고 확장으로 남길 수 있다.

`Default` 대신 `Regular`를 사용하면 400이라는 굵기의 이름과 Recipe가 선택하는
기본 역할도 분리된다. 어떤 Weight를 본문이나 제목에 사용할지는 굵기 이름이
아니라 Recipe가 결정할 수 있다.

## 해결

Terra는 Weight의 기본 범위를 `Regular 400`, `Medium 500`, `Semibold 600`,
`Bold 700`으로 정의한다. `Regular`는 400이라는 굵기를 나타내며 시스템의
기본 사용처를 뜻하지 않는다.

더 가볍거나 무거운 굵기가 필요하면 관습적인 이름과 값을 사용해 기본 범위의
위아래로 확장할 수 있고, 그 밖의 굵기도 실제 필요에 따라 추가할 수 있다.
어떤 Weight를 기본으로 사용하고 정보 위계에 어떻게 배치할지는 Recipe가
결정한다.
