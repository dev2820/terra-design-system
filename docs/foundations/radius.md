# Radius

Radius는 요소 경계의 모서리가 둥근 정도를 나타내는 기하학적 표현이다. Radius
자체는 요소의 중요도, 상태나 용도를 의미하지 않는다.

## 범위

Radius는 다른 Foundation과 독립된 축이며, 모서리를 가진 모든 영역에 공통으로
적용할 수 있다. 원도 Radius의 범위에 포함하지만 선 끝, 아이콘과
일러스트레이션의 곡선은 포함하지 않는다.

## 단계

Terra는 Radius를 `None`, `Radius 1`, `Radius 2`, `Radius 3`, `Full`로
구분한다.

```text
None < Radius 1 < Radius 2 < Radius 3 < Full
```

각 단계는 다음 이름을 사용한다.

```text
radius.none
radius.1
radius.2
radius.3
radius.full
```

숫자는 실제 값이나 배율을 뜻하지 않고 모서리가 둥근 정도의 순서만 나타낸다.

`None`은 모서리를 둥글게 하지 않는 실제 선택지다. `Full`은 요소가 허용하는
최대한의 둥글기를 적용하는 특수한 끝점으로, 요소 크기에 따라 실제 둥글기가
달라진다. `Full`을 같은 너비와 높이를 가진 영역에 적용하면 원이 되고, 서로
다른 너비와 높이를 가진 영역에 적용하면 Capsule이 된다.

## 절대적인 단계

`Radius 1`, `Radius 2`, `Radius 3`은 적용 위치나 요소 크기에 관계없이 각각
같은 절대적인 둥글기를 나타낸다. 단계 사이에 일정한 값의 차이나 배율은
강제하지 않지만 각 단계는 순서에 맞게 시각적으로 구분되어야 한다. 구체적인
값은 Token Set에서 정한다.

## 중첩 관계

시각적으로 연결된 영역이 중첩되면 안쪽과 바깥쪽 모서리는 자연스럽게 이어지는
곡선을 이루어야 한다. Foundation은 정확한 계산식이나 단계 조합을 정하지
않으며, 구체적인 구현은 Recipe에서 결정한다.

## 확장

기본 단계보다 더 많은 Radius가 필요하면 `radius.4`, `radius.5`처럼 숫자를
이어서 추가한다. 새로운 단계는 기존 단계 사이에 삽입하지 않으며 항상
`radius.full`보다 작다.
